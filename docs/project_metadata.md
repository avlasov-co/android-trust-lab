# Canonical Project Metadata

Android Trust Lab uses the following active identifiers:

| Purpose | Canonical identifier |
|---|---|
| Repository URL | `https://github.com/avlasov-co/android-trust-lab` |
| Python distribution | `android-trust-lab-analyzer` |
| Python import package | `trustlab` |
| Command-line interface | `trustlab` |
| Magisk module ID | `androidtrustlab` |
| Citation title | `Android Trust Lab` |

The repository organization slug is independent from the author name. Historical
author attribution remains `Aleksander Vlasov`.

Schema `$id` values use the canonical repository URL followed by the tracked
schema path. `tools/check_metadata.py` validates these identifiers, validates
`CITATION.cff` against the vendored official CFF 1.2 JSON Schema, and scans all
active tracked text so retired repository URLs cannot return.
